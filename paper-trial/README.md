# 独立实时模拟试跑

页面顶部的“Agent决策看板”展示固定规则模块的实际输入、状态、当前结论和下一步。候选目录可点“查看依据”，查看参考价、更新时间、币龄与每条阈值；目录检查不等于入场信号。没有新成交时仍显示目录检查及等待原因。

“实时决策记录”保留真实模块检查与信号评估摘要，包括未通过和未知条件。摘要来自本轮规则及当时可用的观察数据，并非另行调用大模型的交易分析。NEWS尚未接入并明确标示；未进行的费用或信号检查不标通过。最近记录保存在独立账本，重启保留，并按链展示。

打开 http://127.0.0.1:8793/，或双击“启动独立模拟.cmd”。服务依赖已运行的原模拟终端8790，启动器会检查并启动它。关闭网页不停止后台；电脑休眠、原终端停止或本服务停止时，不补造交易。

网页“暂停新仓”仍会处理已有持仓退出；“停止独立模拟.cmd”会停止整个独立试验后台，不停止原研究终端。重启保留账本，并取消中断期间未完成订单，不假定离线成交。

BSC与Robinhood各两组试验，每组200美元虚拟本金：自主选币（内盘与外盘）、观察钱包首买。2026-10-09按用户要求启用Robinhood、暂停BSC新仓，Robinhood内盘仅Pons V2，外盘可使用已解析的V2/V3/V4路线；Pons V1排除。外盘路线或安全字段未核实时可显示等待，但不交易。单次含Gas及授权费的投入上限40美元，准备报价与后续区块撮合均检查绝对上限。调整时四组均无成交，原100美元配置记录保留在历史日志中。

顶部可切换查看的链，每条链各有暂停/启用按钮，另有“暂停全部新仓”。暂停选择存入账本，重启保留；切换查看不会改变是否交易。

它们使用固定规则，尚未证明盈利；新闻与预测市场不在本轮。两链的覆盖窗口、信号、观察计数、资金和24小时新仓窗口分别保存。单链断连或重组只中止该链的准备报价与待成交订单；历史采集缺口只重置后续信号观察，不把仍有新鲜链头的报价误当重组；整个源服务断开或重启会中止两链。暂停只停止新仓，已有持仓继续管理退出。

原终端八组机器人的研究、资金与21＋7天验证门槛继续保留，试验使用独立data目录和数据库。Robinhood必须取得新鲜链头与具体金额的可执行只读报价；来源断连、403或过期时显示等待，不冒充已经成交。

自主选币内盘：上线不足10分钟；需要本轮连续观察60秒，价格突破此前30秒最高价，最新30秒真实成交量至少为此前两倍，买量至少为卖量1.5倍。外盘不设币龄上限，需要连续观察3分钟，对比前后90秒：突破前窗口高点、最新成交量至少为此前1.5倍且买入金额超过卖出金额。外盘信号60秒内有效，开仓报价仍需5秒内核实；这是适应已观测到的回执延迟，不把旧价格改成新价格。钱包首买：只接收原终端名单中观察钱包的首买，必须有成功回执与协议净流核实，60秒内有效，入场溢价不超过10%；不处理启动前事件、重放或加仓。

单次含费用投入最多40美元且不超过净值20%，计划净损失预算为5%。200美元净值下可准备40美元预算，按实际买卖报价核验费用与损失，必要时尝试更小数量。最多同时3个币、每日20次新仓；连续10次净亏或当天净亏达到20%停止新仓。止损预算不保证跳空后损失不超限。账户暂停与观察窗口结束仍继续管理已有持仓。

退出：跌15%止损；涨30%卖原仓50%；减仓后从峰值回落20%或无法覆盖剩余成本退出；最长持有10分钟。触发价不保证成交，未知费用、行情缺口或不可卖会保留余仓及原因。

采用原终端按固定区块、确切金额的只读链上报价，等待500毫秒及后续区块后再报价成交，计入协议费用、税、转换损耗、Gas和首次授权费用估计。没有签名、真实下单或广播接口，试验程序只访问原终端的只读行情流与报价接口。

每条链首次启用后的24小时是其新仓观察窗口，重启不重置；窗口后继续处理退出。本金在首次入场时按该链原生币汇率换算（BSC为BNB，Robinhood为ETH），此后净值包含原生币美元价格波动，不等于全部来自代币择时。未知持仓同时显示参考净值与保守净值，避免用参考价冒充可以卖出的金额。

数据：data/terminal.sqlite保留虚拟流水，data/research-history.sqlite为通用撮合器档案，data/latest-report.json每10秒更新一份状态报告；网页可导出成交CSV。启动日志在data/logs。此试验没有配置定时通知，也不宣称已满24小时或通过盈利验证。

止盈止损对照：同一笔实际模拟入场的数量、成本、买入费用分别镜像至紧止损（8%止损/15%止盈/8%回撤/10分钟）、中等（12%/25%/12%/30分钟）、宽止损（18%/40%/20%/60分钟）。止盈都卖原仓50%。每条链每套方案各200美元虚拟预算、最多3个持仓，三套资金或持仓任一不足则共同跳过该次入场。方案彼此互斥，并非实际同时买三笔。退出按真实数量报价、500毫秒和后续区块计算；未知费用和不可卖不记成交。仅三套全部退出后的完整配对组参与比较，至少20组、5个代币才给出待验证候选，不能保证未来赚钱；回撤指标只含已实现盈亏。

运行验证使用独立 trial-robinhood-check 账本（200U），按真实10U买卖报价、500毫秒和后续区块模拟买入，并在最长30秒后自动退出；费用和盈亏真实按模拟撮合器记账。验证不计入自主策略和退出参数对照，不能作为盈利证据。实时事件先由非阻塞扫描入队，再核验回执；内盘信号期限与撮合统一30秒，报价仍需5秒内核实。事件先到而行情快照后到时，在原信号期限内重试，报价失败不提前消费信号。

实时扫描调整：Robinhood每6秒并行读取日志，回执使用独立有界队列，实时记录优先于历史回放，避免每轮等待所有旧成交核验导致扫描落后。关键原生币汇率使用原有共享API预算中的优先通道。SCOUT、PRICE、SIZE等为固定规则模块，实际交易账户与运行验证账户分别记账。
