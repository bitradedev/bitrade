# 前端交接

2026-10-06 性能更新：`state-cache.ts/reconcileState` 对所有 JSON 字段做结构复用，按 ID 保留未变化的实体，保留完整字段更新、属性删除与列表次序；CSRF 代际变化或链头回退不复用旧代际。`stateSharing.ts/shareAppState` 是兼容导出，实时流与恢复失效逻辑由主任务持有 `useTerminal.ts`。

顶层不再用每秒时钟触发全页重绘。过期状态只在 `ContextBar/StateExpiryWarning` 内更新，浏览观察净值在独立 Provider 内记录；图表、市场行和扫链卡片使用稳定回调与 memo。卡片币龄传入已格式化文本，未变化的币龄不会强制所有卡片重绘。离屏卡片通过 CSS `content-visibility` 跳过绘制，DOM 保留以支持键盘与页面查找；这不是卸载 DOM 的虚拟列表。鼠标或键盘浏览扫链时固定列内次序，行情和阶段仍继续更新。

图表只接收当前代币的成交与行情关键字段。十字光标通过 RAF 合并，在独立读数组件更新；成交标记仅随对应 K 线时间集合或成交记录更新，末根价格/成交量变化不会重复提交相同标记。金额、价格、数量及北京时间格式器缓存复用，显示输出逐项与原格式核对。

性能验证：`tsx --test --test-isolation=none src/client/client.test.tsx src/client/performance.test.ts`，38 项通过；`tsc --noEmit -p tsconfig.json` 通过。`performance.bench.ts` 只读一次本机快照，在内存回放，测量输出保存到 `performance-results.json`。其中引用变更数用于验证实体复用，不是实际浏览器渲染次数或 FPS；JSON 解析仍会分配接收数据。本轮快照 381,089 字节、283 个市场，200 次仅链头变化从 56,600 个新市场引用降至 0；每次改变一个市场降至 200。日期时间格式化 1,000 次从 53.36ms 降至 0.98ms，输出一致。以下旧交接记录反映早期实现，实时流以当前独立 K 线 SSE 与主任务增量状态协议为准。

仅 `src/client/**` 为本次前端实现范围。生产入口是 `main.tsx`，使用项目现有 `index.html`，未修改共享类型、服务器、包配置或锁文件。

- 四页：模拟交易、8 组机器人、研究、复盘。全部读写来自指定本机接口；不导入示例行情，不接入真实钱包。
- POST 使用状态中的 CSRF。操作报错不会被随后的 SSE 心跳抹掉；读取失败单独处理。
- K 线用 Lightweight Charts v5，带真实成交量、十字光标、虚拟成交标记和归属说明。SSE 中代币更新时间、区块或成交时间变动时，合并触发真实 K 线请求（3 秒间隔）；另有 12 秒兜底刷新。不会用参考报价生成 OHLC 或推测成交量。
- 首次展示优先有正价格且已核实的市场，其次有正价格的市场；选择后不因排名变化或列表淘汰而换币。后台 POST `/api/markets/select` 保留当前市场，不阻塞点击或渲染；再次选择同币可重试。K 线展示 `source/pending/reason`，刷新不会因历史补充而一直禁用。
- 净值曲线优先读取实际后台 `health.equity[accountId]` 的 `{at, conservative}` 快照，缺失时仅记录本次浏览观察值。
- 顶部净值是独立账本之和，明确显示人工 / 机器人数量及资金不互通。订单预估金额同时受可用现金、单次投入比例和价格止损风险限制；最终含费用风险由后台报价校验。
- 原仓比例按每个买入批次的 `originalRaw` 计算，最多卖 `remainingRaw`。首卖后成本保护文案对应后台含费用的剩余成本判断。
- 研究使用实际 `ResearchRun`，候选参数表兼容当前 `rules/training/validation/reason` 结果；不填收益。机器人参数变更发送 `{action:'pause', rules, wallets?}`，要求后台创建新版本；仅改钱包时不发送未变更的 `rules`，可使用目前的钱包更新接口。
- 备份下载请求仍带 `Content-Type: application/json` 与 `{}` 请求体，返回完整历史备份。恢复选文件并确认替换后，直接把 `File` 作为 POST `/api/restore` 的请求体，携带 `application/vnd.sqlite3` 与 CSRF；不提前读取整份文件或转成文本。网页恢复上限为 8GB。
- 机器人页显示实际采集记录、报价记录、进行中的任务和采集开始时间。记录总数含未完成数据，不是金融验证门槛；至少 21 天训练验证采集后，还须封存后 7 天独立实时检验，达标前不会启用。
- 复盘的可选 `controlWallets/controlActivity` 只显示你的钱包在当前链已核实且未撤销的买卖。仅展示成交现金流，缺失数值保持未知，不计算真实钱包盈亏，不新增账户或跟单自身。

验证：`tsc --noEmit -p tsconfig.json`、`tsx --test --test-isolation=none src/client/client.test.tsx`，21 项通过；`vite build` 成功。

`ui-test-server.mjs` 是独立界面验收工具，不被产品入口导入。启动前端 8791 后可在 8792 验收；它只有空行情、零成交和明确标识的初始化虚拟账本，不连接外部服务或持久化数据库。生产界面使用真正的 8790 后台。截图 `验收-交易.png` / `验收-研究.png` 是空行情验收画面，不是收益证明。

集成：后台支持从本组32种候选组合创建新实验版本；钱包名单没有变更时前端不发送 `wallets`。“停止全部机器人”使用持久化停止标记，后续研究通过也不会自动恢复新仓。生产界面与后台同在8790端口。
