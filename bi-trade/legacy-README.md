# bi trade — Binance AI Trade

BSC 模拟交易首发版本。当前提供本机可运行的多用户体验，尚未公开部署或发行代币。

## 使用

运行 `Launch.ps1`，打开 http://127.0.0.1:8794/ ，点击“开始模拟”。每个浏览器获得独立会话，两个策略账户各有200U虚拟本金，每笔含费用最多40U。无需充值、连接钱包或签名。

页面上的“暂停我的新仓 / 恢复我的新仓”仅控制自己的账户，已有持仓继续退出。`Stop.ps1`是本机运营者停服务工具，会核验端口、进程和项目路径后再停止；所有用户的模拟会中断，账本保留，离线期间不假定成交。

会话由服务器生成的随机凭据识别，Cookie为HttpOnly、SameSite=Strict，服务器只保存凭据哈希；有效期30天。删除浏览器Cookie会失去当前实验室入口。这版尚未提供跨设备登录或账户恢复。

各用户的现金、持仓、成交、风控、暂停、观察窗口、决策记录和退出对照保存于各自的SQLite目录，只有只读行情共享。关闭页面后模拟继续，服务重启恢复已有账本，取消不确定订单，连续观察重新开始，不补造离线期间成交。新仓窗口从账户创建开始24小时，结束后继续管理持仓退出。

基于已核实BSC行情的突破放量与钱包首买规则，真实金额报价，500毫秒与后续区块后再报价模拟；含协议费、税费、Gas、授权费、价格冲击、失败费用及止盈止损。当前决策模块是固定规则，尚未接入LLM，品牌名称不代表已经具备模型研究能力，也不代表盈利策略已验证。

总览、Agent依据、成交筛选与分页、三套配对退出对照、运行与暂停分别显示。没有记录时明确显示空状态，不填充演示收益。原私有研究界面仍在8793，历史Robinhood记录保留且不进入公共用户账本。

## 部署准备

公开部署需要服务器、HTTPS域名和稳定的BSC行情/RPC来源。服务默认只监听127.0.0.1:8794，可由同机反向代理转发；不得开放原8790行情服务或8793管理服务。配置 `BI_TRADE_PUBLIC_ORIGIN=https://your-domain.example`，代理保留正确Host；HTTPS配置启用Secure Cookie和HSTS，写操作只接受该Origin与自己的CSRF凭据。

允许访问的API只有状态、自己的成交导出、创建独立会话和暂停自己的BSC新仓。没有私钥、充值、提款、真实下单、签名、广播、全站停止或按他人用户ID读取的API。

默认体验容量100个实验室，创建每IP每小时10次；已登录会话写操作每分钟30次、API访问每分钟600次，访客按IP限流。`BI_TRADE_MAX_USERS`可配置容量；扩容前须验证共享报价源容量和延迟。若启用 `BI_TRADE_TRUST_PROXY=1`，必须由同机代理覆盖 `X-Forwarded-For` 为真实单个客户端IP；默认不信任该头。当前依赖本机只读采集器，不应直接宣称已支持无限规模。

## 验证

`node --test bi-trade/test/session-isolation.test.mjs` 验证不同浏览器的账本与暂停隔离、会话凭据、Origin与CSRF检查、重启持久化、私有管理路由不可访问；测试无真实交易。

`node bi-trade/VerifyQuotes.mjs`从已有只读行情源检查BSC的10U买入与同区块整仓反向报价，不生成订单或成交。反向报价包含虚拟买入后的储备变化，质量可能为estimated；完成此检查只表示报价链路可用，不代表真实成交或策略已盈利。

发币准备尚需明确代币名称/符号、供应量、发行方式、分配和用途。此版本没有部署合约，也没有填入未经验证的合约地址或公开收益承诺。
