# bi trade 网站精简改写计划

日期：2026-10-10。范围：功能与页面结构规划；本轮不改动产品代码、交易参数、模拟账本或服务。

## 结论

目前的问题是把策略研究和运行排查的内容放到了普通用户界面。用户需要查看自己的Agent、收益与成交、理解当前判断并控制暂停；无需先理解六个内部模块、完整候选目录和行情核验流程。

建议将主导航从「总览 / Agent / 成交 / 止盈止损 / 运行」收敛为「首页 / 我的Agent / 交易记录」。研究工具保留在管理员入口，个人判断依据保留在Agent详情。

上线目标补充：这是面向公众的BSC模拟交易产品，应具备外部Agent接入能力。界面精简与后台接入能力一起规划；独立用户身份、Agent配对和Agent API纳入首发要求。

## 1. 参考网站有哪些功能

以下根据官网公开页面、登录前Dashboard和官方文档整理。钱包登录后的操作按文档列出，本次没有连接钱包实测。

| 功能 | dotstrade的呈现方式 |
| --- | --- |
| 产品介绍与入门 | 首页说明产品、展示角色、介绍使用步骤，引导创建账户 |
| 账户与Agent管理 | 钱包签名登录；个人控制台创建配对链接、连接Agent、重新连接已有Agent |
| Agent资金与控制 | 专属钱包、余额、充值、暂停、提现和密钥恢复 |
| 战绩展示 | 钱包卡片展示已实现盈亏及未平仓估计结果 |
| 交易记录 | 公共流水、按钱包和网络筛选、翻页、查看链上凭证 |
| 项目代币与说明 | 代币介绍、合约及行情入口、文档、FAQ和社媒链接 |

首页上的战绩、流水和代币栏目可直接看到：[dotstrade首页](https://www.dotstrade.fun/)。登录、配对和资金控制的具体行为见[官方文档](https://www.dotstrade.fun/docs)。

有两个区别需要保留在判断中：官网把角色对话标为装饰动画；官方文档说明研究和持续运行由接入的外部Agent提供。其文档列出的交易执行工具目前针对Robinhood，BNB Chain列为后续网络。因此，不能把首页小人动画当成实时分析，也无需照搬它的多链入口。[首页说明](https://www.dotstrade.fun/#transactions)，[网络与交易文档](https://www.dotstrade.fun/docs#networks)。

## 2. bi trade多出的复杂内容如何处理

| 当前内容 | 问题 | 改写处理 |
| --- | --- | --- |
| SCOUT、PRICE、SIZE、RISK、EXEC、NEWS六模块看板 | 把内部处理流程呈现成用户需要管理的六个对象；实际交易账户只有两个 | 从普通界面移出，直接显示两个实际策略Agent |
| 新闻、预测市场模块 | 当前未接入，却占据独立卡片 | 公共页面移除 |
| 完整候选观察池、逐项核验表 | 目录条目很多，多数并非策略正在考虑的入场机会 | 移到管理员研究页；个人详情只展示近期实际检查的对象 |
| 长篇决策时间线 | 等待、跳过、数据刷新混在一起，阅读负担大 | 每个Agent展示最新一句结论；点击后查看输入、原因、下一步与时间 |
| 三套退出方案、配对样本、盈利因子、回撤表 | 是策略研发工具，不是普通用户日常操作 | 研究计算和数据保留，移到管理员入口；用户按需查看正在使用的退出规则 |
| 运行页的链头、事件数、回放数、核验记录、日志 | 排查信息被当成了主要产品功能 | 普通用户只看运行状态和异常原因，详细诊断保留后台 |
| 巨大总净值卡片及多处重复资金、费用、预算说明 | 同一组数据重复出现，Agent和成交内容被推到下面 | 顶部改为紧凑汇总，主要空间留给Agent卡片与成交 |
| 五个导航入口、单链切换按钮、英文口号与实验室编号 | 当前BSC模拟阶段增加了不必要的学习成本 | 三个主入口；BSC改成标签，编号放帮助详情，缩减重复文案 |

当前公共版已隐藏模拟买卖诊断按钮、Robinhood入口和原研究终端链接，这些不算仍暴露给用户的多余功能；后续继续保持隔离。

## 3. 改写后的页面

### 首页

保留品牌、简短产品说明、一个「开始模拟」按钮和三步入门：开始体验 → 查看Agent判断 → 查看模拟结果。账户未创建时，不展示大量零余额、空流水或运行信息。

FAQ和帮助放页面下方。代币尚未发行时仅保留项目说明与已确认的官方链接；发行后再增加已确认的BSC合约、复制按钮、浏览器和行情链接，不填假地址、假行情或占位购买按钮。

### 我的Agent

顶部用紧凑区域展示总模拟净值、已实现盈亏和当前持仓数。两个Agent各有200U虚拟本金，每笔含费用最多40U，独立账本继续保留。

每个Agent卡片仅显示：名称与角色、当前净值、盈亏、运行状态、最新判断，以及暂停/恢复和详情入口。状态需要明确区分观察中、持仓中、新仓暂停、行情等待、风控暂停和本轮结束。

你之前要求看到Agent的判断依据，这项保留。详情抽屉展示四项：本次读取的数据、采取或跳过动作的原因、下一步、更新时间。依据来自实际策略检查；当前为固定规则模拟，准确标明，不用装饰对话冒充实时研究。

卡片内应支持分别暂停、恢复两个Agent；全局暂停作为辅助操作。暂停新仓后，已有持仓继续按退出规则管理，按钮旁用一句话说明。

「我的Agent」中提供一个「接入自己的Agent」入口：用户创建配对链接，交给自己的Agent完成连接，再看到该Agent的在线状态、模拟账本和判断报告。内置规则体验仍可直接开始，接入流程按需打开。

### 交易记录

默认直接展示模拟成交，列出时间、Agent、币种、买卖方向、金额和已实现净盈亏。只保留基础Agent筛选与翻页，未平仓持仓可在Agent详情查看。

订单详情按需展示状态、费用和执行依据。失败记录仍保存，用户在出现相关失败时看到简短原因并能展开查看，不把内部原始日志作为默认流水。

所有资金和记录继续明确标注「模拟」。模拟成交没有真实链上交易哈希；若提供来源凭证，须标明那是用于观察的原始链上交易。

## 4. 后台保留哪些能力

保留行情时效与路线核验、实际金额报价、费用和滑点检查、账本对账、止盈止损执行、三套退出研究、失败记录、完整审计和用户隔离。

公共页面与公共状态接口只提供用户所需的账户、动作、个人判断与结果。研究和诊断视图单独放到管理员入口，不能只藏起导航后仍把整套研究数据塞给前端。普通用户遇到行情异常时显示易懂的状态，详细链头、回放和核验信息由管理员查看。

界面精简不会放宽入场条件，不会关闭风险检查，也不会删除已有成交或研究记录。

## 5. 上线所需的Agent API

当前代码只提供浏览器会话、查看状态、成交导出和暂停接口；外部Agent尚不能注册或提交模拟交易。用户身份目前依靠浏览器会话，公开产品应补充可恢复、可跨设备的用户身份及其所属Agent关系；首发可用钱包签名登录，仅用于身份认证，仍保持虚拟资金模式。

Agent API可以部署在网站同一域名的`/api/v1/`路径，共用后台。每个Agent获得自己独立、可撤销的访问凭据，只能访问绑定的模拟账户。浏览器登录凭据和模型服务的API key不交给外部Agent。

| 首发能力 | 作用 |
| --- | --- |
| 配对与连接管理 | 用户生成有时效、一次性的配对链接；Agent注册后领取独立凭据；用户可断开和重新连接 |
| 读取行情、账户与持仓 | 向Agent提供可用行情、数据时间、虚拟预算和当前持仓 |
| 提交模拟买卖 | Agent提交交易意图和唯一请求编号；后台核验行情、报价、费用、预算及暂停状态后处理 |
| 查询订单与结果 | 区分准备、等待、模拟成交、拒绝和失败；超时重试同一请求不得重复开仓 |
| 上报判断摘要和运行心跳 | 页面展示Agent提交的判断、引用的数据和下一步；区分Agent报告与平台已核实事实，显示在线或离线 |

每个Agent初始200U、每笔含费用最多40U，限制由后台统一执行。Agent无法改写资金余额、成交价格、已实现盈亏、暂停状态或风控门槛。真实行情报价产生模拟成交，Agent提交的文字不作为成交证明。

同一账户只使用一个入场决策来源：内置规则或外部Agent。接入外部Agent时切换来源，避免两个运行程序同时开仓；平台继续负责已有持仓的退出管理。外部Agent离线、用户暂停或风控触发后，停止接收该Agent的新仓意图，并保留持仓退出与账本记录。

先提供普通HTTPS API与接入文档，再按客户端需要增加MCP入口；两者调用同一套权限和模拟执行逻辑。[参考站的API与MCP接入说明](https://www.dotstrade.fun/docs#agent-api)。

模型API是另一项能力：若由bi trade托管真正的AI研究Agent，后台还需接入模型服务、行情工具和持续运行的任务程序。平台可以统一管理模型API key，按用户和Agent统计调用量并限制用量；不必为每个Agent购买一套独立模型API。若用户自带已运行的外部Agent，bi trade只提供平台接口，无需替该Agent运行其模型。

## 6. 改写顺序与验收

1. **先改结构。** 分开访客首页和个人控制台，收敛三个导航入口；移出研究、诊断和未接入模块。
2. **建立接入与账户能力。** 补充用户身份、Agent配对和专用API；实现独立凭据、预算核验、订单幂等与入场决策来源切换。
3. **完善用户操作与显示。** 压缩汇总卡，增加单Agent暂停/恢复、判断详情和连接状态，整理成交表；校验手机布局、空状态、异常状态与数据更新时间。

验收标准：新用户无需阅读研究文档就能开始模拟；进入个人页面能直接看到两个Agent的结果和状态；判断依据最多再点一次即可看到；暂停一个Agent不影响另一个或其他用户；行情不可用、风控暂停和本轮结束都不会伪装成正在交易；账本、交易上限与退出逻辑保持正确。

接入验收：外部测试Agent能完成配对、读取自己的账户、提交一笔真实行情报价的模拟订单并查询结果；其他Agent的账户不可读写；重复请求不会重复成交；被撤销凭据和暂停账户不能开新仓；已有内置策略不会与外部Agent重复控制同一账户。

本次上线版暂不新增真钱充值/提现、私钥托管或恢复、多链选择及额外策略套餐。模型托管方式、公开战绩展示和实盘功能作为后续独立范围确定；外部Agent接入与可恢复账户已纳入首发计划。
