# 检查文档处理记录

日期：2026-10-10。原评估针对旧版 `441e062`；本记录说明当前修改及仍未完成的部分。

## 已处理

- **反向代理限流**：本地 Node 服务只接受显式配置的可信代理 IP；从代理链右端选择访客地址，忽略不可信来源的转发头。验证通过的 Owner 和 Agent 分别计数。Cloudflare 使用平台提供的访客地址，限流数据持久保存。
- **行情和风控代理不一致**：两者统一使用 `PAPER_PROXY`，支持 `direct` 直连；请求时间校正支持 IPv4 直连。保留只读接口和认证限制。
- **遗漏前端测试**：默认测试命令同时运行服务端及两份前端测试，分别在独立进程中执行，避免前端网络模拟影响服务端检查。新增 GitHub Actions 构建、测试和云端打包检查。
- **账本扫描及可读性**：为 Owner、Agent 添加 SQLite 索引；账户状态、订单、持仓与账户交易历史使用范围查询。格式化核心逻辑，云端与本地复用同一套权限、模拟执行与账本模块。
- **生产部署**：迁移至 Cloudflare Worker 与 SQLite Durable Object，保留原账户、钱包地址和模拟历史；真钱操作固定关闭。本机不再需要持续运行交易服务。
- **主页与入场**：直接打开根域名进入滚动动画；点击入口进入 `/home`。新版主页增加 Agent 动态网络、流动连线、策略流程和卡片层次。深浅色、双语、暂停动效与减少动态效果偏好继续支持。首屏先显示，再加载账户与公开数据。

## 验证

产品 60 项、Cloudflare 9 项、研究终端服务端 353 项及前端 43 项，共 **465 项通过**。构建和 Cloudflare 打包通过。检查包含真实 Workerd 的 SQLite 隔离、重启恢复、权限与资金锁定；网络报价和模型决策测试仍有模拟数据，不能替代生产持续运行验证。

已在浏览器检查根入口、进入主页、动效暂停、深色与英文、手机布局。
